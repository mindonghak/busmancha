# 버스만차 유입 확대 우선순위

## 먼저 실행

1. 네이버 서치어드바이저와 Google Search Console에서 사이트 소유권 확인,
   사이트맵 제출, 수집/색인 상태 확인. 계정 소유자의 로그인 및 인증이 필요하다.
   사이트맵: https://busmancha.vercel.app/sitemap.xml
2. 공개 중인 네 노선에 한해 검색 가능한 개별 URL을 만든다. 예를 들어
   M4137 정류장별 만차 통계 페이지에는 방향, 실제 관측 기간, 표본 수와
   결과를 서버에서 렌더링한다. 내용 없는 노선 페이지를 대량 생성하지 않는다.
3. 버스·정류장·방향·필터를 유지하는 결과 공유 링크를 추가한다. 이용자가
   공유받은 화면에서 같은 결과를 바로 볼 수 있게 한다.

## 초기 이용자 확보 실험

- 동탄 지역 커뮤니티와 해당 노선 통근자 모임의 홍보 규정을 확인하고,
  허용되는 곳에만 서비스 소개와 피드백 요청을 올린다. 이번 작업에서는
  외부 게시물을 작성하거나 발송하지 않았다.
- 제목 예시: "M4137 타시는 분들, 정류장별 과거 만차 기록을 모아봤습니다".
  실시간 예측이나 탑승 보장으로 홍보하지 않는다. 그래프에는 기간·표본을 포함한다.
- 처음 2주는 광고비보다 인터뷰와 사용성 확인에 집중한다. 유입 경로별
  방문자, 실제 조회 실행 비율, 일주일 내 재방문을 비교한다. 수치 목표는
  현재 기준치를 확인한 뒤 정한다. 봇/본인 테스트를 방문자 성과로 세지 않는다.
- 자료가 충분해지면 노선별 주간 요약을 게시한다. 표본이 부족하거나
  수집이 끊긴 기간은 명시하고, 작은 표본으로 혼잡 순위를 단정하지 않는다.

## 이번 반영 범위

기본 검색 제목·설명, canonical URL, Open Graph 텍스트, robots.txt,
sitemap.xml을 추가했다. 검색 서비스 소유권 인증, 개별 노선 페이지,
공유 링크 및 캠페인별 방문 측정은 아직 구현/등록하지 않았다.
메타정보나 사이트맵만으로 검색 노출 또는 방문자 증가가 보장되지는 않는다.
